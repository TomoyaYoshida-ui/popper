# 科研工作台

当前是单用户、本地 Web 工作台，不新增研究状态源。所有实验、审批、确认及 Claim 仍由现有服务和 Research Kernel 写入。

## 使用

最左侧图标栏打开会话、Study、项目文件、实验运行和设置。侧栏按项目文件夹组织真实持久会话：箭头仅展开，项目名称恢复该项目上次会话，子会话打开明确的所属项目。搜索同时匹配项目名和会话标题；最近会话默认折叠，最多十条。重命名、归档及恢复均校验元数据版本，运行中须先停止才能归档，不提供永久删除。旧 Quest 仅在高级工具的“历史任务”中只读查看。默认纯白主题，已有主题选择保留。

中间对话独立于右侧标签。输入框支持 Enter 发送、Shift+Enter 换行和中文输入法。停止、转向、失败重试及会话预算仍调用原有接口。模型标签展示实际配置，而非固定名称。

右侧默认显示 Study。工具结果中的关联对象，以及 Study 中的 Job、Observation、Claim、稿件链接，会打开对象标签；重复打开定位已有标签。方向键、Home/End 切换标签。分隔条可拖动，聚焦后可用方向键调整。最大化只隐藏对话，不销毁它。

项目文件采用中间文件内容、右侧可搜索目录树的布局。“打开文件”标签未选文件时只显示选择提示；点击目录文件打开独立标签，重复打开定位已有标签。目录树在文件标签之间共享，搜索保留目录层级；当前文件自动展开父目录并高亮。工具栏文件夹按钮可收起目录，显示偏好随项目布局恢复；收起目录不卸载编辑器或清空草稿。目录范围仍是当前登记项目，不因界面改造扩大到磁盘或上级目录。Monaco 编辑器按需加载，支持行号、高亮、查找、撤销与差异。普通文件保存先预览差异，再使用原字节摘要写回；冻结输入仍只读，必须通过既有 Revision 流程创建修订。证据绑定稿件保持只读；可编辑的已登记产物支持编辑、预览及版本校验保存。

底部三个入口具有不同语义：交互终端是真实 Shell，运行日志展示作业状态，事件审计展示已发生事件。Ctrl+` 打开或收起终端，Ctrl+B 切换侧栏，Alt+N 新建会话。收起、切换底部工具或切换工作标签不会结束 Shell；“结束终端”及项目切换会关闭旧会话。刷新后创建新 Shell，不声称恢复进程。

1024px 默认收起侧栏；900px 以下使用“对话 / 工作区”切换。响应式切换只是隐藏面板，不删除输入和编辑状态。支持可见键盘焦点与系统减少动画偏好。

## 恢复与保存边界

### 新会话如何继续任务

新会话中的交接卡只展示候选，不自动发送消息或运行研究。“继续此任务”先核对目标、约束、决定、待办、阻塞与下一步；确认后创建不可变修订并关联当前会话，点击对话输入区发送才调用模型。没有语义摘要时明确展示有来源的对话摘录；Agent 建议不自动成为用户决定。

通过“任务上下文”可修订、选择其他任务，或解除关联并开始新任务。解除关联不删除任务、旧会话、Study、稿件或预算。一个项目可以有多个任务，一个任务可由多个会话接续；任务不等于旧 Quest。同项目会话及来源跳转保留项目文件、编辑草稿与 Shell，输入草稿仍分别属于各会话。

关联研究只读取用户选定 Study 的最新预算、Job、Observation、Claim 和稿件摘要，不把旧交接变成第二套科研事实。来源、研究版本或任务修订变化时需要重新核对，保留人工填写；旧审批仍在原会话，不能通过交接继承权限。确认超时后先重新读取核对；相同内容重试复用持久幂等标识，不重复创建任务或修订。

模型输入统一用于发送、工具续推理、转向及人工重试。`POPPER_CONTEXT_MAX_BYTES` 默认为 65536（允许 4096–1048576），限制序列化 `system/messages/tools` 的 UTF-8 字节数，不是精确 token 数。较早历史按完整消息组精简，并标识来源摘录和省略的可选研究事实；当前输入、必要规则或完整最新消息组不能容纳时拒绝调用，不静默截断。预算预留和执行读取同一持久输入快照，不自动追加额度。

有效 JSON 字符串会解析后递归脱敏并保持字符串类型；预览、交接、来源和模型数据使用同一规则，工具定义与实际执行参数不被改写。旧修订仅脱敏读取投影，不重写历史；旧持久输入若发现未脱敏凭据则阻止调用，需人工核对后重试。规则覆盖声明的敏感字段、常见密钥/Bearer 格式和已配置环境凭据，不是任意秘密的通用检测器；不要主动在研究目标或聊天里填写密钥。

会话数据库采用添加表的兼容升级；只读候选查询不迁移旧库、不转换旧会话/Quest。布局版本与 IndexedDB 草稿键不变。接口及本轮实际验证范围见 [任务交接安全修复与验收](task-context-acceptance-2026-10-01.md)。

布局、文件标签、当前 Study、分栏及底部面板存于 localStorage，归属于项目；对话输入和阅读位置归属于会话。编辑草稿存于 IndexedDB，按项目和文件归属保存。同项目切换会话只更新对话，保留编辑器实例、未保存内容和 Shell。关闭标签或跨项目切换提供保存、放弃、取消；取消不发送切换请求。项目准备/导入也经过同一未保存保护，不整页强制刷新。

项目级布局键为 `popper-workbench:v1:<project>:workspace`。首次迁移优先采用当前会话的旧布局，再按会话更新时间合并有效标签并去重；旧布局键和 IndexedDB 草稿键不删除。切换期间暂停发送及写操作，HTTP/SSE 用上下文版本丢弃迟到结果。Study 属于项目研究对象，切换会话不会创建、运行或确认 Study。

恢复草稿会核对磁盘 SHA-256。版本不同先进入差异视图，未经处理的冲突不会因再次打开或自动保存草稿而被解除。选择“保留草稿并继续审查”明确采用当前磁盘版本为新基准；实际写回仍由服务端核对版本。浏览器清理站点数据会删除本地草稿；多个浏览器页同时编辑同一文件不是协作模式，磁盘写回校验仍生效。

资源加载失败由面板错误边界隔离，不让单个编辑器使整个工作台白屏。部署更新后旧页面可能仍引用旧的懒加载块，需要重新载入工作台；草稿和布局使用上述本地存储恢复。Monaco 主懒加载块约 777.30 kB gzip，比全功能注册基线 1,042.47 kB 降低 25.44%，不会加入首次对话页的主块；JSON 语言服务另按需加载约 255.73 kB gzip。构建仍会报告大块警告，不代表全部编辑器资源都降低了同样比例。

## 开发与检查

工作台已统一圆角容器、层次背景、字阶与本地 SVG 图标；四主题保留原存储偏好。设置主题支持 Escape 返回焦点，标签切换或缩窄窗口会定位当前标签。实际截图、测试和未验证边界见 [整体 UI 收敛记录](ui-design-acceptance-2026-10-01.md)。

后端默认在 8765。前端在 `frontend/` 执行 `npm ci`、`npm run dev -- --host 127.0.0.1`，开发页在 5173。代理只转换该开发页自身的 Origin，其他 Origin 仍由后端拒绝，不取消 CSRF 或可信本地校验。

前端检查：`npm test --prefix frontend`、`npm run build --prefix frontend`。构建后执行 `python scripts/stage_frontend.py`，并用 `--check` 核对包内资源。Python 回归：`python -m pytest -q`。

此前的工作台收尾验收使用独立临时项目，不修改已有实验结果：ODE convergence-order-v1 与 WDBC binary-accuracy-v1 均实际完成协议校验、Study 登记、开发运行、独立确认审批、Claim 和证据绑定稿件；从稿件跳转证据并核验本机制品绑定成功。另验证真实 PowerShell 在收起/标签切换后保留变量、1440px/1024px/窄窗口布局、标签恢复、草稿恢复和未保存关闭保护。以下测试数字和模型用量属于该历史验收；本轮项目内会话改造的独立记录见 [项目会话与共享工作区验收](project-sessions-acceptance-2026-09-30.md)。

自动交互测试覆盖标签去重、StrictMode 恢复、IME、失败发送保留输入、键盘标签、模态焦点、取消/放弃/保存失败、终端组件保持、IndexedDB 队列，以及恢复冲突跨重挂载仍保持原基准。新增审批重复点击、审批版本过期、工具结果版本、迟到响应及四主题正文色对比度回归，前端共 29 项通过。Python 全量回归为 995 passed、5 skipped、544 subtests passed。

真实 MiMo 验收仅使用合成临时项目。原 20,000 token 预算因预留检查阻止续推理后，用户明确授权提高到 4,000,000；保留历史用量和最多 3 次请求限制，续推理已成功返回实际文件标记与 SHA-256。累计 2 次请求、10,118 tokens，刷新后会话、结果及未提交输入保持；流式文本草稿已持久化。没有第三次请求或自动付费重试。本地 OpenAI 兼容模拟服务通过真实后端和 SSE 验证异常分支。Linux 原生终端、团队权限与分布式执行不在范围内。详细边界和复查结果见 [收尾验收记录](workbench-acceptance-2026-09-30.md)。
