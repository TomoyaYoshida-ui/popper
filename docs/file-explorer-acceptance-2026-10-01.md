# 文件工作区改造 — 2026-10-01

按用户参考图改为中间文件内容、右侧目录树。未选择文件的“打开文件”标签只显示居中提示，不再把整个目录列表作为独立主页面。选中文件仍通过统一 openResource 打开独立编辑标签；重复打开定位已有标签。
