# Agent 真实科研验证：离线准备记录

## 当前结论

本批完成轨迹领域评估器、参考解交叉核验、固定 RK4 开发基线、不可覆盖的离线准备入口和跨运行预算账本。**尚未完成整个计划，也尚未证明 Agent 的科研能力。** 未发送真实模型请求、未执行独立确认、未读取或改写既有研究资源。

旧 `cross_domain_kernel_benchmark` 保持无模型定位，没有改名或把其中的 Claim 当作 Agent 证据。

## 已实现

- `oscillator-trajectory-v1` 通过已有 Domain Pack 注册机制接入，无 Research Kernel 修改。标准库评分；候选只交轨迹，拒绝自报误差、能量或求值次数。
- 主指标：按案例等权平均的归一化轨迹 RMS；位置与速度/频率同时评分。诊断包含相对初始能量的最大漂移；缺失/失败案例不得删掉，显式失败罚分为 1,000,000。
- 谐振子解析参考解；非线性摆 DOP853、RK45 和收紧精度 DOP853 三次核验。归一化最大分歧门槛固定为 `1e-8`，失败即中止准备，不调宽门槛。
- 每划分 32 个全因子案例：2 系统 × 2 频率 × 2 初始振幅 × 2 时长 × 2 求值预算。开发和确认频率、时长不同；每案例冻结 65 个观察时间点。
- RK4 基线由可信宿主执行，计量每次 RHS 请求。这只证明固定基线的计量，**不证明任意候选代码的防篡改计量**。
- 数据文件、参考核验、开发基线与协议保留 SHA-256；现有目录拒绝覆盖。候选可见目录不含参考轨迹或确认数据。目录分离不是访问权限隔离，禁止把整个评测目录作为 Agent 可读项目。
- 独立预算账本在 SQLite 中保存请求快照和累计用量，默认总上限 60 次/400,000 tokens；需与现有会话预留同时使用。未知用量、超预留或重启后的未结算请求阻止继续调用；同请求 ID 不自动重发。输入快照复用现有脱敏规则。
