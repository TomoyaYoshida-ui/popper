# 证据驱动的科研判断

研究存储新增 `judgment` 追加实体，沿用已有事件链/快照表，不覆盖历史记录。
每项记录绑定假设版本、旧/新判断、观察引用、范围、后续行动和独立评估制品。
未完成执行为 `not_evaluated`，不能作为反证；点估计达标不能自动变成科学支持。
旧运行没有 `judgment_schema` 标记时继续保持“未记录”，不自动补造历史判断。

判断只能通过内核从已验证观察推导。分组比较在单独进程完成，重算配对样本、
树预测、规则预算和 bootstrap 区间；记录和审计都校验其文件摘要与重算结果。
决策和模型反思引用判断及原始观察。模型可以解释证据，不能写入自己的分数。

保留原有预测结果、Hypothesis/Claim 阈值状态以兼容既有数据；它们是描述性状态。
新增科研判断与它们分开显示，判断即使支持预测，也不证明机制。
FIGS 的两个竞争解释分别检验改善 > 0.05、改善位于 [-0.05,0.05]。

新增可选 `confirmation_train`：初始化时必须逐条等于冻结 train + dev，
确认阶段才使用，不能包含测试标签；全部文件进入输入哈希。
外部签名确认合同暂不支持此选项，明确拒绝，不静默替换训练身份。

验证：相关原项目回归 96 passed、7 subtests passed；追加判断与替代证据的
验证 87 passed、9 subtests passed。覆盖旧库副本不回填、重复幂等、事件重放、
执行失败不反驳、制品篡改拒绝，以及相同预测随证据变化改变判断与后续行动。
